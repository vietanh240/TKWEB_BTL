# 📖 Giới Thiệu

Hệ thống quản lý điểm học tập là một ứng dụng web được xây dựng để hỗ trợ giáo viên và nhà trường trong việc quản lý, theo dõi và đánh giá kết quả học tập của học sinh/sinh viên.

# ✨ Tính Năng Chính

- 👨‍🏫 Quản lý học sinh: Thêm, sửa, xóa thông tin học sinh

- 📚 Quản lý môn học: Thiết lập danh sách môn học và hệ số điểm

- 📊 Nhập điểm: Nhập điểm các hệ số (15 phút, 45 phút, học kỳ)

- 📈 Thống kê & Báo cáo: Xem điểm trung bình, xếp loại học lực

- 🔍 Tìm kiếm: Tìm kiếm học sinh theo tên, lớp

- 📁 Xuất dữ liệu: Xuất bảng điểm ra file PDF/Excel

- 👥 Phân quyền: Quản lý truy cập cho giáo viên và admin

# 🛠 Công Nghệ Sử Dụng

# 🚀 Cách Sử Dụng

### 1. Truy cập trang web
- Truy cập: https://vietanh240.github.io/TKWEB_BTL/

- Sử dụng trên trình duyệt Chrome, Firefox, Edge phiên bản mới nhất

### 2. Đăng nhập
- Tài khoản giáo viên: Xem và nhập điểm

- Tài khoản admin: Toàn quyền quản lý hệ thống

### 3. Quản lý dữ liệu
- Thêm học sinh: Vào mục "Học sinh" → "Thêm mới"

- Thêm môn học: Vào mục "Môn học" → "Thêm môn"

- Nhập điểm: Chọn học sinh → Chọn môn → Nhập điểm hệ số

- Xem báo cáo: Vào mục "Báo cáo" để xem thống kê
